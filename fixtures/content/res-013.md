# Retrieval-Augmented Generation for Knowledge-Intensive NLP Tasks (summary excerpt)

## Approach
The paper combines parametric memory (a pre-trained sequence-to-sequence generator, BART) with non-parametric memory (a dense vector index of Wikipedia passages accessed through a neural retriever based on DPR). For each input, the retriever returns the top-k passages and the generator conditions on them.

## Variants
Two formulations are compared. RAG-Sequence uses the same retrieved passage to generate the entire output sequence. RAG-Token can draw on a different passage for each generated token, marginalising over passages per token.

## Findings
RAG models set strong results on open-domain question answering benchmarks and produced more specific and factual text than a parametric-only baseline. Because knowledge lives in the index, it can be updated by swapping the document index without retraining the generator.

## Limitations
Quality depends on retrieval quality, and the model can still generate content not supported by retrieved passages.
